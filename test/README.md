# test

A simple tester for `MultiStageStochasticBlock`.

It builds a `MultiStageStochasticBlock`, solves it and checks the results,
exercising the basic machinery of the module. The `makefile` builds the
executable including the `MultiStageStochasticBlock` module and the core SMS++
library.
